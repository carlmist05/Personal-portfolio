# Eugene Mwenda — Professional Portfolio

A responsive professional portfolio website for Eugene Mwenda, a Diploma in Computer Science student. The site highlights my skills, learning journey, selected projects, and professional contact links.

## Live website

Add your published portfolio link here once the website is online.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Dark theme with high-contrast accent colours
- About, skills, selected-work, experience, and contact sections
- Direct links to LinkedIn, GitHub, and email
- Smooth scrolling and subtle reveal animations

## Built with

- HTML5
- CSS3
- JavaScript

## Run locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.

For automatic browser refreshes while editing, install the **Live Server** extension in VS Code and open `index.html` with Live Server.
